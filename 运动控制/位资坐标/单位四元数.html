2. 最重要的一个公式

q = ( cos(θ/2),  sin(θ/2)·nx,  sin(θ/2)·ny,  sin(θ/2)·nz )
       ↑ w              ↑ x, y, z：轴的方向，按比例缩放

例子：绕 z 轴转 90°。轴 n = (0, 0, 1)，θ/2 = 45°，cos 45° ≈ sin 45° ≈ 0.71，所以

q = (0.71, 0×0.71, 0×0.71, 1×0.71) = (0.71, 0, 0, 0.71)

可以在第 2 步里把仰角拉到 90°（轴朝正上方，就是 z 轴），θ 设成 90°，验证一下。

怎么理解这 4 个数

  • w 说的是“转了多少”：不转时 w = 1，转得越多 w 越小。
  • x、y、z 说的是“绕哪根轴转”：它们的方向就是轴的方向。
  • 四个数的平方和永远是 1，所以叫“单位”四元数。程序里如果算出来不等于 1，就要“归一化”把它拉回来。
  • q 和 −q 表示同一个姿态，这是半角 θ/2 带来的（第 3 步）。

暂时可以跳过的部分

教科书会把四元数写成 w + xi + yj + zk，并有一套 i² = j² = k² = −1 的乘法规则，用来推导“两次旋转怎么合成一次”。零基础先掌握上面的内容就够了，学旋转合成时再回来看会顺很多。

3. 插值：为什么四元数比欧拉角好

什么是插值？机器人手臂从姿态 A 转到姿态 B，不能一下子跳过去，得算出中间每一刻的姿态，一帧一帧地走。用 t 表示进度：t = 0 在 A，t = 1 在 B，t = 0.5 就是半路。

什么是欧拉角？把旋转拆成三个角度：绕 z 转多少（偏航）、绕 y 转多少（俯仰）、绕 x 转多少（横滚）。最直接的插值做法是让这三个数各自匀速地从 A 的值变到 B 的值，问题就出在这里。

问题出在哪？欧拉角插值只是把三个数字各自匀速变化，并不知道它们合起来代表空间里的哪个姿态：

  • 场景 1，绕远路：170° 和 −170° 在数字上差 340，但在空间里只差 20°。欧拉角只认数字，所以真的转了 340°。
  • 场景 2，走弯路：三个角度各自匀速变化，但“先绕 z、再绕 y、再绕 x”是叠在一起起作用的，合起来机头走出一条歪扭的路，转得比需要的多，转速也不均匀。

四元数为什么没这个问题？任何两个姿态之间，都能找到一根轴，只绕它转一次就到位。slerp 就是找到这根轴，沿着它匀速转过去，所以机头走的总是一段圆弧，转的角度正好等于 A 和 B 实际相差的角度。对机器人来说，绕远路浪费时间、可能撞到东西，转速忽快忽慢电机也受不了。

4. 四元数是怎么“知道”两个姿态很近的？

靠一次很简单的计算：把两个四元数的 4 个数对应相乘再加起来，叫“点积”。结果越接近 1（或 −1），两个姿态就越接近。用场景 1 的数字一步步算：

第 1 步：把 A 和 B 写成四元数

两个都是绕 z 轴转，套公式 q = (cos(θ/2), 0, 0, sin(θ/2))：

A：θ = 170°，θ/2 = 85°     q_A = ( 0.087,  0,  0,  0.996)
B：θ = −170°，θ/2 = −85°   q_B = ( 0.087,  0,  0, −0.996)

看起来 q_A 和 q_B 也差很远：最后一个数一正一负。

第 2 步：想起“q 和 −q 是同一个姿态”

B 也可以写成 −q_B，4 个数全部变号：

−q_B = (−0.087,  0,  0,  0.996)
q_A  = ( 0.087,  0,  0,  0.996)

这下两组数几乎一样了。B 换了一种写法，马上就和 A 挨在一起。

第 3 步：用点积量一量有多近

q_A · q_B    = 0.087×0.087 + 0 + 0 + 0.996×(−0.996) = −0.985
q_A · (−q_B) =   −0.0076   + 0 + 0 +      0.992     =  0.985
slerp 的规则：如果点积是负的，就把 B 变号，改用 −q_B。这一步保证它总是走近的那条路。

第 4 步：把“有多近”换算成角度

点积 = cos(两个四元数之间的夹角)
夹角 = arccos(0.985) ≈ 10°
实际要转的角度 = 2 × 10° = 20°

为什么 ×2？因为四元数里装的是半角 θ/2，换算回真实角度要乘 2。

四元数并不是“聪明”，而是它的数字天生就和空间里的姿态对得上：姿态挨得近，四元数的 4 个数也挨得近（最多差一个正负号，查一下点积正负就能处理）。欧拉角没有这个性质：170° 和 −170° 在空间里挨着，数字上却一个在最大端、一个在最小端，中间隔着 ±180° 这条“接缝”。
