三关节机械臂：先在墙里算，再转身

从平面机械臂走向 3D 的第一步。不用 4×4 矩阵，只用你已经会的"乌龟"和 cos、sin。

1. 认识这台机械臂 · 2. 肩膀和手肘只在一面墙里动 · 3. 把墙平放着看：算 r 和 z · 4. 底座转身：什么变、什么不变 · 5. 从天花板往下看：把 r 拆成 x、y · 6. 合起来 · 练习题 · 总览动画
这一章的核心一句话：3D 三关节机械臂 = 平面两节手臂（肩膀 + 手肘） + 底座转身。
① 用 θ₂、θ₃ 在竖直的墙里算出 r（往前多远）和 z（多高）
② 用 θ₁ 把 r 拆成 x、y，z 不变

1 + 2. 认识这台机械臂：肩膀和手肘只在一面"墙"里动

一台最常见的三关节机械臂（工业机械臂的前三轴就是这样）：

  • 关节 1（底座）：整台机械臂绕竖直轴原地转身
  • 关节 2（肩膀）：把大臂抬起来
  • 关节 3（手肘）：弯小臂

先点"显示那面墙"，再一次只动一个关节：

两句话：

  1. 肩膀和手肘动的时候，手臂一直待在那面墙里，不会跑出去。所以只看肩膀和手肘，它就是一条立起来的平面两节手臂，和第 8 题一样，只是从"平躺在地上"变成了"竖起来贴在墙上"。
  2. 底座动的时候，整面墙跟着原地转。手臂在墙里的样子完全不变，只是朝向变了。

3. 把墙平放着看：算 r 和 z

站在墙的正前方看，这面墙就是一张平面的纸：横着是"离底座往前多远"，记作 r；竖着是"离地面多高"，记作 z。乌龟从肩膀 (0, 1) 出发，一开始面朝正前方：先转 θ₂、走 1.5（大臂），再转 θ₃、走 1.2（小臂）。

只用一条规则（单位圆学过）：面朝角度 φ 走 L 步，往前走了 L × cos φ，往上走了 L × sin φ。
第二段走的方向是 θ₂ + θ₃，因为乌龟转了两次，角度要加起来。
例子：θ₂ = 90°，θ₃ = −90°

起点：肩膀 (0, 1)

走大臂：面朝 90°（朝正上方），走 1.5
  往前 1.5 × cos 90° = 1.5 × 0 = 0
  往上 1.5 × sin 90° = 1.5 × 1 = 1.5
  到达手肘 (0, 2.5)

再转 −90°：面朝 90° + (−90°) = 0°（朝正前方）

走小臂：面朝 0°，走 1.2
  往前 1.2 × cos 0° = 1.2 × 1 = 1.2
  往上 1.2 × sin 0° = 1.2 × 0 = 0

末端：r = 0 + 0 + 1.2 = 1.2
      z = 1 + 1.5 + 0 = 2.5

这一步的作用：3D 末端要 3 个数 (x, y, z)。这一步算出了 z（已经是最终答案）和 r（还要拆成 x、y）。和之前平面手臂的区别只有两个：起点在肩膀 (0, 1)，不在 (0, 0)；横轴叫 r，竖轴叫 z。

4. 底座转身：什么变了，什么没变

底座转身时，z 和 r 都不变，只有"往前"的方向变了，转到了 θ₁ 的方向。就像坐在转椅上、手平伸在前面：椅子一转，手的高度不变，手离身体的距离也不变，只是手指的方向变了。

5. 从天花板往下看：把 r 拆成 x、y

从正上方往下看，高度 z 看不见了。末端在地面上的影子，就是一根从底座出发、长 r、朝 θ₁ 方向的线。

一根长 r、朝 θ₁ 方向的线：
x = r × cos θ₁
y = r × sin θ₁

r = 1.2 的例子：
θ₁ = 0°：  x = 1.2 × cos 0°  = 1.2 × 1 = 1.2
           y = 1.2 × sin 0°  = 1.2 × 0 = 0
θ₁ = 90°： x = 1.2 × cos 90° = 1.2 × 0 = 0
           y = 1.2 × sin 90° = 1.2 × 1 = 1.2

6. 合起来：三个角各管一件事

θ₂、θ₃（大臂、小臂）→ 决定 r（往前多远）和 z（多高）     ← 在墙里算
θ₁（底座）          → 决定"往前"朝哪个方向，把 r 分成 x 和 y，不碰 z

x = r × cos θ₁
y = r × sin θ₁
z 不变
常见误解："θ₁ 影响 x、y，θ₂、θ₃ 只影响 z"——只对一半。θ₂、θ₃ 也决定 r，而 r 会进到 x、y 的计算里，所以它们也会间接影响 x、y。例如 θ₁ = 0° 不转身，只把大臂从竖直放平，末端往前伸出去，x 就变大了。准确地说：θ₁ 只影响 x、y，不影响 z；θ₂、θ₃ 决定 r 和 z。

为什么还要学 DH？

"墙 + 转身"这个办法很直观，但只适合这种结构简单的机械臂。真实的六轴机械臂手腕还有三个关节，转轴朝向各不相同，就拆不成"一面墙"了。所以工程上统一用 DH 表来算。下一课会把这台三关节机械臂写成 DH 表，用矩阵算一遍，结果和这里一样；DH 表里的 α₁ = 90°，其实就是"把墙竖起来"。
