齐次变换矩阵：补充讲解

配合《齐次变换矩阵.html》一起看。这里收集了学习过程中卡住过的几个问题，每个都配了动画。

1. θ₁ 是哪个角 · 2. B 的轴为什么是 (cos θ₂, sin θ₂) · 3. 方向从 A 翻译到世界 · 4. 矩阵相乘一格一格算 · 5. 补 1 还是补 0 · 6. 按行算和按列看

1. θ₁ 是哪个角？

θ₁ 是 A 的 x 轴和世界 x 轴之间的夹角，也就是 A 相对世界转了多少度。A 自己的 x 轴和 y 轴之间永远是 90°，整个 A 坐标系像一个焊死的直角，转的时候 x_A 和 y_A 一起转。

在机械臂里，θ₁ 就是关节 1 转过的角度。θ₂ 是 B 的 x 轴和 A 的 x 轴之间的夹角，也就是关节 2 相对第一节手臂转了多少。T_WA 第 1 列是 (1, 0) 时，说明 cos θ₁ = 1、sin θ₁ = 0，也就是 θ₁ = 0°。

2. B 的轴为什么是 (cos θ₂, sin θ₂)？

一根长度为 1 的箭头，从 A 的 x 轴开始逆时针转了一个角度。从箭头尖端向两根轴各画一条虚线，得到一个直角三角形：箭头是斜边（长 1），横边长 cos(角度)，竖边长 sin(角度)。所以这根箭头的坐标就是 (cos 角度, sin 角度)。

  • B 的 x 轴：和 x_A 夹角 θ₂ → (cos θ₂, sin θ₂)
  • B 的 y 轴：比 B 的 x 轴多转 90°，和 x_A 夹角 θ₂ + 90° → (cos(θ₂+90°), sin(θ₂+90°)) = (−sin θ₂, cos θ₂)
角度从哪量：统一从 x_A 开始、逆时针量，这样才能都套 (cos, sin) 这一个公式。
坐标的两个数：第 1 个数 = 沿 x_A 走多少，第 2 个数 = 沿 y_A 走多少。所以 (0, 1) 的意思是"沿 x_A 走 0、沿 y_A 走 1"，正好指向 y_A。

θ₂ = 0° 时：B 的 x 轴 = (cos 0°, sin 0°) = (1, 0)，B 的 y 轴 = (cos 90°, sin 90°) = (0, 1)，B 没有相对 A 转动。

3. 方向从 A 翻译到世界

左图站在 A 上看，右图放到世界里看。"走法"不变（沿 x_A 走几步、沿 y_A 走几步），只是 x_A 和 y_A 跟着 A 转了 θ₁。默认是 θ₁ = 0°、θ₂ = 90°，试着把 θ₁ 拖到 90°。

例子：θ₁ = 0°，θ₂ = 90°

T_WA = ⎡ 1.00   0.00   0.30 ⎤      B 的 x 轴在 A 里：v = (0, 1, 0)
       ⎢ 0.00   1.00   0.30 ⎥
       ⎣ 0.00   0.00   1.00 ⎦

算 x：第 1 行 (1.00, 0.00, 0.30) 和 (0, 1, 0)：1.00×0 + 0.00×1 + 0.30×0 = 0
算 y：第 2 行 (0.00, 1.00, 0.30) 和 (0, 1, 0)：0.00×0 + 1.00×1 + 0.30×0 = 1

结果 (0, 1)：和输入一样，因为 θ₁ = 0°，A 没转，"在 A 里朝上"就是"在世界里朝上"。
0.30 × 0 = 0：方向不管 A 被挪到哪，平移被挡掉了。

换成 θ₁ = 90°

T_WA 第 1 行变成 (0, −1, 0.30)，第 2 行变成 (1, 0, 0.30)

x = 0×0 + (−1)×1 + 0.30×0 = −1
y = 1×0 +    0×1 + 0.30×0 =  0      → B 的 x 轴在世界里朝左
（A 先转了 90°，B 又在 A 上再转 90°，一共 180°）
在 A 里读出来的东西，要先用 T_WA 翻译成世界的话，才能和世界里的东西放在一起算（比如相加）。

4. 矩阵相乘：一格一格算

T_WB 第 i 行第 j 列的数 = T_WA 的第 i 行和 T_AB 的第 j 列对应位置相乘，再加起来。下面一列一列往下算：每算完一列，就得到 B 的一样东西。

  • 第 1 列算完：B 的 x 轴在世界里朝哪
  • 第 2 列算完：B 的 y 轴在世界里朝哪
  • 第 3 列算完：B 的原点在世界里的位置
每一列的第 3 个数：前两列（方向）是 0，第 3 列（位置）是 1。所以 T_WA 的平移 0.30 只在第 3 列被加进来（0.30 × 1），在前两列被挡掉（0.30 × 0）。这也是最下面一行永远是 0 0 1 的原因。

5. 补 1 还是补 0？

问自己一句："这是一个地方，还是一个朝向？"

B 的位置、末端、物体上的点      →  地方  →  补 1（要加平移）
x_B、y_B、手臂的朝向            →  朝向  →  补 0（不加平移）

例子：底座 A 在 (0, 1)，θ₁ = 180°，B 在 A 里是 (2, 0)。

T_WA = ⎡ −1   0   0 ⎤
       ⎢  0  −1   1 ⎥
       ⎣  0   0   1 ⎦

补 1：T_WA × (2, 0, 1)
  第 1 行：(−1)×2 +   0×0  + 0×1 = −2
  第 2 行：  0×2  + (−1)×0 + 1×1 =  1      → B = (−2, 1)  ✓

补 0：T_WA × (2, 0, 0)
  第 1 行：(−1)×2 +   0×0  + 0×0 = −2
  第 2 行：  0×2  + (−1)×0 + 1×0 =  0      → (−2, 0)  ✗ 少了底座的位置 (0, 1)

其实不用自己判断：(2, 0, 1) 就是 T_AB 最右一列原样拿过来的，它的第 3 个数本来就是 1。

T_AB 右下角那个 1 和 θ₂、距离都无关：每一个齐次变换矩阵最下面一行都固定是 0 0 1。

6. 按行算和按列看，是同一件事

按行算是做法，按列看是意思。同一个乘法：

⎡ −1   0   0 ⎤   ⎡ 2 ⎤
⎢  0  −1   1 ⎥ × ⎢ 0 ⎥
⎣  0   0   1 ⎦   ⎣ 1 ⎦

按行算：
x =  (−1)×2   +    0×0    +   0×1   = −2
y =    0×2    +  (−1)×0   +   1×1   =  1

把每一竖排单独看：
第 1 竖排：(−1) 和 0  → 矩阵最左一列，都乘了 2
第 2 竖排：0 和 (−1)  → 矩阵中间一列，都乘了 0
第 3 竖排：0 和 1     → 矩阵最右一列，都乘了 1

自己算的时候，用按行算就行。按列看只是为了理解每一项在干什么：最右一列是 A 的位置，乘 1 就是"把 A 的位置加进来"。
